DailyBread respects your privacy.

This Privacy Policy explains what information we collect and how it is used. Discord is a platform that DailyBread uses; by using DailyBread, you agree to Discord's Terms of Service and Policies.

1. Information We Collect

When you use DailyBread through Discord OAuth2, we may collect:

  • Discord user ID
  • username
  • global display name
  • avatar
  • guild/server IDs
  • channel IDs
  • webhook configuration data
  • embed content
  • scripture references
  • webhook delivery logs

2. How Information Is Used

Collected information is used solely to:

  • authenticate users,
  • manage Discord server integrations,
  • send embeds through Discord webhooks,
  • improve DailyBread functionality,
  • maintain system security and reliability.

3. Data Sharing

DailyBread does not sell user data.

Information is only shared with:

  • Discord APIs required for functionality,
  • infrastructure providers required to operate the service.

4. Data Storage

Data is stored securely using Supabase and related infrastructure providers.

Webhook URLs are stored securely and are never exposed publicly.

5. User Control

Users may disconnect DailyBread at any time by:

  • removing the bot from servers,
  • revoking OAuth2 access through Discord.

6. Security

Reasonable measures are taken to protect stored data, but no system can guarantee absolute security.

7. Children's Privacy

DailyBread is not directed toward children under 13.

8. Changes to This Policy

This Privacy Policy may be updated periodically.

Continued use of DailyBread after updates constitutes acceptance of the revised policy.

9. Contact

For privacy-related questions, contact the DailyBread team through the official support server or website.

DailyBread strives to provide reliable platform functionality and secure data storage. However, service availability may occasionally be affected by Discord API limitations, third-party outages, infrastructure interruptions, software bugs, or network issues. While reasonable efforts are made to maintain reliable operation and preserve stored data, DailyBread cannot guarantee uninterrupted service, permanent data retention, or successful message delivery in all circumstances.
